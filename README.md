# 观澜 · 20万量化实验室

以人民币 **200,000 元**为初始本金的跨市场模拟投资项目，用可核对的行情、财报、成交记录和资金流水检验策略表现。涵盖美股、A股、港股、加密货币与部分指数 ETF，所有交易均为模拟交易。

## 功能与规则

- 展示净资产、累计盈亏、现金、持仓、交易计划和历史成交。
- 分别显示做多/做空方向、持仓占净资产比例及账户整体杠杆；持仓 14.1% 不代表单只股票使用 0.141 倍融资杠杆。
- 支持模拟融资及符合条件的美股假设借券卖空；总敞口上限为净资产的 2 倍。
- 新计划等待下一完整交易日，纳入滑点、交易费用、融资与借券成本，不补填错过的成交。
- 报价展示与交易账本分离：更新报价不会触发交易。保留来源时间、缓存、限流和数据缺失状态。
- A股、港股财报尚未接入完整核验，缺失核验的标的不能自动买入；公开行情不保证交易所级实时性。

详细策略见 [v2 策略说明](docs/upgrade-v2.md)，日常操作见 [每日运行说明](docs/daily-run.md)。

## 技术与目录

Node.js 22.13.0+、React、Vinext、Vite、Cloudflare Workers / D1、Drizzle。

| 路径 | 用途 |
| --- | --- |
| `app/` | 中文仪表盘、账户与报价接口 |
| `lib/` | 策略、数据采集、模拟成交、融资和估值 |
| `scripts/daily.mjs` | 采集、校验、保存每日账本并读回核对 |
| `scripts/quotes-watch.mjs` | 独立报价更新，不执行交易 |
| `db/`、`drizzle/` | 数据库定义与迁移 |
| `tests/` | 模拟交易、风控、数据校验和报价测试 |

## 运行模拟账户

先在当前进程中安全注入以下环境变量，再运行脚本：

| 环境变量 | 含义 |
| --- | --- |
| `QUANT_SITE_URL` | 已授权的私有站点 HTTPS 地址 |
| `QUANT_SITE_TOKEN` | 该站点已有的访问令牌；不得写入源码、提交或日志 |

```sh
node scripts/daily.mjs
node scripts/quotes-watch.mjs --once
```

第二条命令只更新一次报价。持续报价使用 `node scripts/quotes-watch.mjs`，须先确认没有已有报价进程，避免重复服务。每日研究和持续报价依赖采集程序所在的电脑或服务运行；网页轮询不会自行完成每日研究。

## 数据保存范围

线上账户的本金、持仓、完整成交历史和最新行情保存在 D1 中，不包含在本源码仓库内。`lib/seed.json` 是初始化研究数据，不是当前账户备份。依赖、构建产物、本地运行文件和环境凭据均通过 `.gitignore` 排除。
